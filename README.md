# My Portfolio

This is my personal portfolio website. I built it to introduce myself as a Front-End Developer and to show the projects I have worked on so far.

## Live Demo
 [View my portfolio](https://youssef231120.github.io/portofolio-youssef/)

## What's Inside
- **Home:** an introduction with my photo and links to my social accounts
- **About:** a short bio and quick info cards (location, education, skills)
- **Projects:** cards for the websites I built, each with a live link
- **Contact:** a contact form so visitors can send me a message
- **Footer:** my name and social links

## Details I Worked On
- Responsive layout using Bootstrap's grid system
- Collapsible navigation bar that closes after clicking a link
- Smooth scrolling between sections
- Hover effects and animations on cards, buttons, and icons
- Working contact form using Formspree

## Tools I Used
- HTML5
- CSS3
- Bootstrap 5
- Font Awesome
- JavaScript (small script for the navbar)
- Formspree (contact form)
